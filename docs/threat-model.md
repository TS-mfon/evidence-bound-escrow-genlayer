# Threat model

The contract defends against fabricated citations, stale or uncommitted submissions, prompt injection in evidence, malformed model output, external-source failure, duplicate finalization, unauthorized delivery, caller-supplied appeal prompt injection, replayed appeals, permanent escrow lockup, and premature refunds. URLs are bounded and committed before review; unavailable evidence cannot produce an accepted result. Appeals are party-authorized in storage and bounded to one per case, guaranteeing that a finalized review cannot be reopened indefinitely.

Recovery controls are state- and deadline-based. Only the sponsor can recover an `OPEN` case, and only after no delivery arrived before the seven-day submission deadline. A respondent delivery after that deadline is rejected. A submitted case cannot recover when consensus finds every locked URL available. If consensus finds an outage, recovery first records the exact unavailable set and waits three more days; the eventual recovery requires the outage to persist for at least one originally missing URL. Recovery pays the escrow only to the sponsor and moves the case to terminal `RECOVERED`, so it cannot be replayed or used to divert funds to the respondent.
